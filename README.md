# C++ Practice & Foundations 🚀

This repository is where I'm keeping the C++ programs I write while learning. It mostly contains small practice programs covering the fundamentals of C++, along with logic and math-based problems. I'll keep adding more as I learn new concepts and continue building my understanding of the language.

---

## 📂 What's in this repository?

So far, you'll find programs related to:

* Variables and data types
* Input and output
* Operators
* Conditional statements
* Loops
* Basic number and logic problems

Each program is focused on helping me understand and practice a specific concept.

---

## 🛠️ Compiling and Running

Clone the repository:

```bash
git clone https://github.com/Anshita-C/Learning_CPP.git
cd Learning_CPP
```

Compile any program with g++:

```bash
g++ path/to/program.cpp -o program
```


Run it:

```bash
./program
```
