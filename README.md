* Variables and data types

* Operators
* Conditional statements
* Loops
* Basic number and logic problems

Each program is focused on helping me understand and practice a specific concept.

---

## 🛠️ Compiling and Running

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/cpp-practice-lab.git
cd cpp-practice-lab
```

Compile any program with g++:

```bash
g++ path/to/program.cpp -o program
```

For example:

```bash
g++ 02-control-flow/fibonacci_series.cpp -o fibonacci
```

Run it:

```bash
./program
```
